# my-rust-ai

Власний проєкт нейромережі / ШІ на мові Rust, створений з нуля для експериментів та розвитку архітектури.

## Структура проєкту

- `src/tensor.rs` — базові матричні/тензорні операції.
- `src/network.rs` — багатошаровий перцептрон (MLP) та зворотне поширення помилки.
- `src/lib.rs` — публічний API бібліотеки.
- `src/main.rs` — базовий запуск.
- `examples/xor.rs` — приклад навчання на задачі XOR.

## Запуск

cargo run
cargo run --example xor
